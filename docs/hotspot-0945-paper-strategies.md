# 热点策略双账户 30 日模拟

该实验同时运行两个隔离的本地模拟账户：

| 策略 | AlphaSift 候选池 | 初始资金 | 单笔目标 | 最多持仓 |
| --- | --- | ---: | ---: | ---: |
| `hotspot_oversold_reversal_0945_v1` | `oversold_reversal` | 100,000 元 | 当前权益 25% | 2 |
| `hotspot_trend_reacceleration_0945_v1` | `momentum_quality` | 100,000 元 | 当前权益 25% | 2 |

两个账户使用 `broker=paper_0945`，不会切换或污染当前 `vnpy_paper` 账户。账户、成交、费用和每日净值进入 Portfolio 账本；活动进度及逐日决策证据写入 `data/hotspot_0945_paper/`，该目录属于本地运行数据，不入库。

## 前向执行契约

- 工作日 09:28 准备并冻结两个 AlphaSift 候选池；09:30 至 09:35 每 15 秒刷新带供应商时间戳的实时开盘价、最高价、最低价、最新价和累计量价。
- 行情必须不超过 120 秒；采集会跳过不提供供应商时间戳的数据源并继续回退，所有候选的可用性或拒绝原因写入当日审计。所有数据源均缺时间戳、字段缺失或错过 09:30–09:35 买入窗口时失败关闭，09:35 后不补单。
- 超跌策略在任一盯盘采样点要求相对开盘至少上涨 1.5%、自低点反弹至少 1%；趋势策略要求相对开盘至少上涨 2%、自低点反弹至少 0.5%且重新站上累计 VWAP。
- 两者都只允许综合排名前二、位于早盘区间上部的候选进入下单判断。
- 条件首次满足时立即再取第二份实时行情并加入 5 bps 滑点模拟成交；第二份行情若在 09:35 后才返回则放弃该买单。每个策略在窗口内最多新增一只，不存在绕过硬门槛的强制买入。
- A 股数量向下取整为 100 股整手，执行双边万 0.8、最低 5 元佣金，双边万 0.1 过户费和卖出万 5 印花税。
- 卖出策略在下一交易日 09:27 读取 09:25 已形成的开盘集合竞价价格与前收盘价；竞价涨幅低于 5% 时，在 09:30 使用新的带供应商时间戳行情模拟卖出。竞价涨幅达到或超过 5% 时，从 09:30 至 09:45 每 15 秒检查一次当日最高价与行情源给出的 `limit_up_price`。
- 前 15 分钟内触及涨停价则当日继续持有，不再启动移动止盈；未触及涨停且涨停价证据完整时，09:45 后启动移动止盈并持续盯盘至 14:54。超跌反转使用从当日峰值回撤 2% 的止盈线，趋势再加速使用 3% 的止盈线；14:55 收盘阶段再做一次末次检查和净值估值。
- 所有卖出遵守 T+1，并计入卖出滑点、佣金、过户费和印花税。缺少竞价价、前收盘价、涨停价或实时行情时失败关闭并保守持有，缺失原因写入 `exit-watch` 审计；活动满 30 个合格交易日后的清仓仍作为行政性收尾保留。原 3% 硬止损、成本保护、开盘价/VWAP 弱势确认和最长持仓期卖出条件已全部停用。
- 只有当天至少存在一个候选，且开盘决策和收盘估值证据都完整时，才推进一个真实交易日；空候选池会记录为失败证据，不消耗 30 日进度。每个账户累计 30 个合格交易日后停止新买入，并在后续可卖时清仓。

## 看板与人工因子

Web 模拟交易页可在两个热点账户和跨市场账户之间切换查看；该选择不会改变实际执行账户。热点账户当前可人工配置的全部账户级运行因子包括：单票目标权益比例、最大持仓数、开盘涨幅/低点反弹/早盘区间门槛、是否要求 VWAP 确认、开盘涨幅/反弹/AlphaSift 上游分/抗跌性/VWAP 五项最终评分权重、候选池数量、允许下单排名、次日竞价阈值和移动止盈回撤。

热点覆盖值写入 `data/hotspot_0945_paper/factor_overrides.json`，按策略 ID 隔离，并在每次策略阶段开始时加载。后端拒绝越界、错误类型、零总权重和排名大于候选池数量等无效组合。保存只影响后续判断，不重算历史决策；恢复默认会移除该策略的人工覆盖。

## 安装与检查

首次创建账户：

```powershell
python scripts/run_hotspot_0945_paper_30d.py --setup
```

管理员 PowerShell 安装 Windows 计划任务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install_hotspot_0945_paper_30d_task.ps1
```

安装脚本会注册两个 SYSTEM 任务：`DailyStockAnalysis-Hotspot0927ExitWatch30D` 在工作日 09:27 启动竞价/移动止盈盯盘，`DailyStockAnalysis-Hotspot0945Paper30D` 在 09:28 和 14:55 负责准备 09:30–09:35 入场盯盘与收盘估值；任务名和策略 ID 中的 `0945` 仅作为兼容标识保留。非交易日由交易日历失败关闭。查看当前进度：

```powershell
python scripts/run_hotspot_0945_paper_30d.py --phase status
```

此功能只做模拟交易，不连接真实券商，也不构成投资建议。
